# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Josh Andrew Esmade's personal CV and developer portfolio. Visitors can learn about Josh, browse projects and skills, download the résumé, and find contact and social links.

## Capabilities and Constraints

- Existing React, TypeScript, and Vite application in `CV_front/`.
- Four hash-routed sections: Home, About me, Projects, and Contact.
- Preserve profile copy, real project details, portrait, toolbox icons, certificates, résumé download, project filters and detail dialogs, and contact destinations.
- Preserve a light/dark theme control and remember the preference for the console palette.
- The user wants the new design applied across all pages, with a slimmer mobile frame.

## Brand Commitments

The user selected and authorized the Pocket console concept: a beige outer frame, green LCD-style content area, chunky pixel borders, and a triangular menu cursor. The framed layout must make the previously empty desktop margins feel intentional. Retain the existing pixel heading typeface and handle `jaesmade`.

## Evidence on Hand

- Real profile and project content in `CV_front/src/data/portfolio.ts`.
- Existing portrait, locally hosted fonts, toolbox marks, résumé PDF, and project artwork in the app.
- Approved concept: panel A, Pocket console, of the retro concept board. The other two panels were not selected.

## Product Principles

- Present the real CV immediately and keep section navigation direct.
- Preserve factual content while applying the approved visual direction.
- Make the console frame useful on large screens and compact on mobile.
- Keep keyboard navigation, readable text, and responsive layouts.
